# Coner Beta Releases

Release channel for the Coner private beta on macOS.

This repository holds only release artifacts. The application source lives
elsewhere; nothing here is published to a package registry.

It is public because the in-app updater fetches `latest.json` without
credentials.

## Install

Download the latest `.dmg` from the [Releases](../../releases) page and drag the
app into `/Applications`.

Requirements: Apple Silicon, macOS 26 or later.

Updates install themselves in the background; the app offers a restart when a
new version is ready.
